# 符文远征 · Rune Expedition

原创暗黑奇幻 H5 试玩作品。手机或电脑浏览器即开即玩，中英文切换，默认中文。

**Play:** https://cassiee-z.github.io/rune-expedition/

## 玩法

骑士自动追击，玩家决定技能时机和装备组合。三场战斗、两次三选一装备、一个最终 Boss，完整体验约 3 分钟。

- 符文爆发：全场伤害，8 秒冷却。
- 誓约护盾：持续约 4 秒，11 秒冷却；在红色预警出现时使用。
- 灼烧、暴击、守护三种方向，可组合为九种构筑。
- 键盘：1 / 空格释放爆发，2 / Q 开启护盾，Esc 暂停。
- 离开页面自动暂停；支持关闭声音。

## 作品范围

个人概念验证 Demo，借助 AI 编程工具制作。Canvas 场景、角色及 SVG 图标由代码绘制，音乐与音效通过 Web Audio 实时合成。无外部素材、第三方运行依赖、真实付费或广告接入。

中英文版本共用同一套战斗逻辑。结束后展示本局真实伤害、装备选择、技能使用、护盾抵挡等数据；最近五次记录仅存于当前浏览器，可手动清除、导出 JSON。本作品未采集线上用户数据，不能据此声称具备真实留存、付费率或商业成绩。

该作品展示小游戏核心循环、基础本地化和数据记录的实现思路，不代表任何公司的已发行游戏或官方合作项目。平台 SDK、账号、支付、广告、服务器、APP 打包及上线审核均不在当前 Demo 范围内。

## 本地运行

需要 Node.js 18+ 运行测试，Python 3 或任意静态服务器用于预览。

```sh
python3 -m http.server 8765
# 打开 http://localhost:8765
node tests/engine.test.js
```

## 文件

- `engine.js`：独立战斗模型、装备、Boss 逻辑与本局事件。
- `art.js`：Canvas 场景、角色和特效。
- `audio.js`：Web Audio 背景音与音效。
- `app.js`：界面、双语文本、交互、浏览器本地记录。
- `style.css`、`index.html`：响应式布局与页面结构。
- `tests/engine.test.js`：九种装备组合、五组随机种子及暂停、护盾、结算等行为测试。
