# 符文远征 · Rune Expedition

原创暗黑奇幻 H5 试玩作品。手机或电脑浏览器即开即玩，中英文切换，默认中文。

[在线试玩](https://cassiee-z.github.io/rune-expedition/?v=20260923)

## 剑盾战斗更新 · v2

默认手动挥剑，保留自动选敌和接近目标；可随时切换自动攻击。三章战斗、两次装备选择和最终 Boss，支持九种装备组合。

- 连续点按挥剑：斜劈、反斩、刺击。最多预存下一剑，动作到命中帧才计算伤害。
- 按住举盾，松开解除。盾只保护正面；临近命中时举盾触发完美格挡，随后 2.2 秒内挥剑可反击。
- 持盾时点击挥剑可盾击，消耗 20 耐力，可打断普通敌人。
- 点地移动、点敌切换目标。走位优先于自动追击。
- 闪避消耗 22 耐力，冷却 2.2 秒；有短暂无敌时间，可取消出招。
- 符文爆发消耗 30 耐力，冷却 8 秒，只伤害附近敌人。
- 橙色扇形攻击可格挡；红圈地面震击不能格挡，需要走出范围或闪避。
- 耐力耗尽会破防，无法无限举盾。
- 键盘：WASD / 方向键移动，J / 1 挥剑，按住 Q / K / 2 举盾，空格 / L / 3 闪避，E / 4 爆发，M 切换模式，Esc 暂停。
- 切换页面或窗口会暂停；可关闭声音。

## 作品范围

个人概念验证 Demo，借助 AI 编程工具制作。Canvas 场景、角色及 SVG 图标由代码绘制，音乐与音效通过 Web Audio 实时合成。无外部素材、第三方运行依赖、真实付费或广告接入。

中英文版本共用战斗逻辑。每局记录真实伤害、装备选择、格挡、反击、连招终结、闪避等数据；最近五次记录仅存于当前浏览器，可清除、导出 JSON。未采集线上用户数据，没有真实留存、付费率或商业成绩。

本作品不代表任何公司的已发行游戏或官方合作项目。平台 SDK、账号、支付、广告、服务器、APP 打包及上线审核不在本 Demo 范围内。

## 本地运行与构建

直接双击 `index.html` 即可运行，请保留同目录的 `game.js`、`style.css` 和 `icon.svg`。交付包中的 `符文远征-双击即玩.html` 已内嵌所有资源，单个文件即可离线试玩。手机链接使用上方在线地址。

修改源码后，用 Node.js 18+ 构建；构建工具只在开发时使用。

```sh
npm ci
npm test
npm run build
```

## 文件与验证

- `engine.js`：独立战斗模型、装备、敌人攻击预警和本局事件。
- `motion.js`：独立剑击姿态与两段手臂关节计算。
- `art.js`：Canvas 场景、角色、刀光和攻击范围提示。
- `audio.js`：Web Audio 背景音与音效。
- `app.js`：双语界面、鼠标 / 触控 / 键盘交互和本地记录。
- `build.mjs`：生成经典脚本 `game.js` 和单文件离线版。
- `tests/engine.test.js`：14 项战斗规则与动作轨迹检查。
- `tests/balance.test.js`：九种装备 × 五个随机种子的主动防守模拟，以及纯自动对照。

模拟用于排查可通关性与规则问题，不等同于真人体验测试或商业数据。
